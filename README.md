# Ishakulam - Gurukul of Excellence

Welcome to the Ishakulam website repository! Ishakulam is a premier residential boarding school blending ancient Gurukul wisdom with modern education. This repository contains both the React frontend and the Node.js backend.

## Project Structure

- `src/`: Contains the frontend React code (Vite + React + TypeScript + Tailwind CSS).
- `backend/`: Contains the Node.js Express API.

## Features

- **Modern UI:** Built with Tailwind CSS and shadcn/ui.
- **Responsive:** Mobile-first approach for all screen sizes.
- **Backend API:** Custom Node.js Express server to handle contact forms.
- **SEO Optimized:** Metadata and fast loading performance.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Frontend Setup
1. Open a terminal in the root directory.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. The frontend will be running on `http://localhost:8080`.

### Backend Setup
1. Open a second terminal and navigate to the `backend` directory:
   ```bash
   cd backend
   ```
2. Install backend dependencies:
   ```bash
   npm install
   ```
3. Start the backend server:
   ```bash
   npm run dev
   ```
4. The backend will be running on `http://localhost:5001`.

## Deployment

- **Frontend:** Currently deployed to GitHub Pages using the `npm run deploy` script.
- **Backend:** Ready to be hosted on Render.com, Railway, or any Node.js hosting provider.
